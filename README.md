# Sepia · Controlador de fluido Ø10 mm

Site estático (um único `index.html`, sem build e sem dependências externas).

## Publicar na Vercel
1. `npm i -g vercel` (ou use o painel em vercel.com/new)
2. Dentro desta pasta: `vercel --prod`
   - Framework: **Other**; Build command: vazio; Output directory: `.`

Abas com link direto: `/#purga`, `/#gas`, `/#co2`, `/#agua`, `/#3d`.
